# 🔐 Генератор паролей

Простое веб-приложение для генерации надёжных паролей (чистый HTML/CSS/JS, без сборки и зависимостей).

## Возможности
- Криптостойкая генерация через `crypto.getRandomValues` (Web Crypto API) с устранением modulo bias
- Настройка длины (4–64 символов)
- Выбор наборов: заглавные, строчные буквы, цифры, спецсимволы
- Опция «без похожих символов» (Il1O0o|)
- Гарантируется минимум один символ из каждого выбранного набора + перемешивание Fisher-Yates
- Индикатор надёжности на основе оценки энтропии (в битах)
- Копирование в буфер обмена одним кликом
- Тёмный адаптивный интерфейс

## Запуск

Вариант 1 — просто открыть файл: откройте index.html в браузере двойным кликом.

Вариант 2 — через локальный сервер (рекомендуется, чтобы работал Clipboard API):
```bash
python3 -m http.server 8000
# затем откройте http://localhost:8000
```

## Структура
```
index.html   — разметка
style.css    — стили (тёмная тема)
script.js    — логика генерации и UI
```
